KURYEPLAN SON TRAFIK DÜZELTMESİ

Bu paket mevcut projeye ek/düzeltme dosyalarını içerir. Repo klasörünü silmeyin ve .git klasörüne dokunmayın.

1) Bu ZIP'i şu klasöre çıkarın ve dosyaların üzerine yazın:
   C:\Users\Oguzhan Sapmaz\Desktop\kurye-cikis-saati-planlayici

2) Anaconda Prompt'ta proje klasöründe çalıştırın:
   python -m unittest discover -s tests -v
   node --check traffic-dashboard.js
   node --check app.js
   node --check map.js

3) Testler OK ise:
   git add scripts/fetch_ibb_traffic.py traffic-dashboard.js vercel.json nginx/default.conf tests/test_traffic_pipeline.py tests/test_ui_contract.py docs/assignment-status.md
   git commit -m "Make IBB traffic fallback resilient"
   git push

4) GitHub Actions'ta 'İBB trafik verisini güncelle' iş akışını açıp Run workflow ile başlatın.

ÖNEMLİ: Bu düzeltme, İBB API GitHub runner'dan zaman aşımına uğradığında son geçerli veriyi korur (ilk çalıştırmada boş şemayı koruyabilir) ve işin tekrar tekrar kırmızıya düşmesini engeller. Arayüz ayrıca resmi İBB API'sini tarayıcıdan denemeyi dener. Bu, dış API'ye erişim garanti etmez. İBB API hem GitHub hem tarayıcıdan erişilemezse gösterge paneli gerçek olmayan trafik değeri üretmez; veri kaynağı erişimi doğrulanmadan canlı veri var sayılmamalıdır.
