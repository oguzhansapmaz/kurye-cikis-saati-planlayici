# Kanıt klasörü

Buraya yalnızca gerçekten sizin bilgisayarınızda/hesabınızda alınmış kanıtları ekleyin. Başlangıçta klasör boş olması normaldir. Önerilen dosyalar: `container-user.png`, `readonly-test.png`, `trivy-before.json`, `trivy-after.json`, `github-actions-run.png`, `zap-before.html`, `zap-after.html`, `headers.png`, `budget-alert.png`, `monitoring-alert.png`. İçeriği hassas olan loglar, token/anahtarlar veya hesap bilgileri bu public depoya konmamalıdır.
